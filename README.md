# express-savage-demo

A demonstration web-application built with Express and styled with the swagger of 21 Savage – a fun, minimal full-stack app that showcases server-side rendering and static assets.

---

## Features

- Server side built with Express — modular and lightweight  
- Views rendered with EJS templates  
- Static assets served from a `public/` folder (CSS, JS, images)  
- Quick demo of routing, view engine configuration, and asset delivery  
- Ideal for prototyping or learning Express fundamentals  

---

1. Clone the repository:  
   ```bash
   git clone https://github.com/AngelBelRoth/express-savage-demo.git
   cd express-savage-demo

## Installation

1. run `npm install`
2. run `npm run savage`
3. Navigate to `localhost:3000`
